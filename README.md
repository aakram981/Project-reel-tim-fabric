# Real-Time Analytics with Microsoft Fabric – Bike Sharing

End-to-end Real-Time Intelligence project: Eventstream ingestion,
tumbling-window aggregation (sum of bikes per street), Eventhouse (KQL)
storage, and a live Real-Time Dashboard.

**Stack:** Microsoft Fabric · Eventstream · Eventhouse · KQL · Real-Time Dashboard
